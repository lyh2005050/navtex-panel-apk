# NAVTEX海事警告接收面板APK
这是一个安卓端NAVTEX海事航行警告接收APP，专门用于接收上海海岸台518kHz英文、486kHz中文航行警告，同时支持收听4215kHz XSG摩尔斯信标。

## 功能
- 实时连接上海公开SDR节点
- 自动解码NAVTEX航行警告
- 实时显示信号强度、信噪比
- 手机端原生体验，不用浏览器

## 安装
直接下载Releases里的APK安装即可，支持安卓8.0以上所有手机。

## 使用
1. 安装APK后打开
2. 自动连接上海SDR节点
3. 调谐到518kHz即可接收英文航行警告，486kHz接收中文警告
4. 切到CW模式可收听4215kHz XSG摩尔斯信标

## 编译
本仓库使用GitHub Actions云端自动编译，不需要本地Android环境，提交代码后自动打包APK。
